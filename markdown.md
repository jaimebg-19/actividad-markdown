# Ciberseguridad

## Cómo proteger tu información en el mundo digital

La **ciberseguridad** es el conjunto de técnicas y buenas prácticas que protegen los sistemas, las redes y los datos frente a ataques informáticos. Hoy en día es *imprescindible* tanto para empresas como para usuarios particulares, porque casi toda nuestra vida pasa por internet. Un ejemplo sencillo es comprobar que una web usa `https` antes de introducir una contraseña. 

```
contraseña = input("Introduce una contraseña: ")

if len (contraseña) >= 12:
    print ("Contraseña segura")
else:
    print("Contraseña débil")
```

### Tipos de amenazas 

- Malware
- Phishing
- Ransomware
- Ataques de fuerza bruta

### Pasos para crear una contraseña segura

1. Usa al menos 12 caracteres
2. Combina letras, números y símbolos
3. No reutilices contraseñas
4. Activa la verificación en dos pasos
